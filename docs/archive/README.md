# 历史归档文档

本目录存放已经归档的历史或过期文档。

使用规则：

- 这些文档保留审计轨迹、阶段性判断和历史背景，便于回溯。
- 这些文档默认不是当前实现、当前架构、当前验收结果的真相源。
- 如果归档文档与仓库根下的 `docs/` 基线文档、当前源码、当前测试结果冲突，以当前基线文档和最新代码/测试结果为准。
- 使用归档文档时，必须先阅读文件头的“过期原因”“替代真相源”和“禁止用途”。
- 根目录阶段性文件 `task_plan.md`、`findings.md`、`progress.md` 已迁入本目录，作为 `docs/archive/task_plan-2026-05-03-to-2026-05-05.md`、`docs/archive/findings-2026-05-03-to-2026-05-05.md`、`docs/archive/progress-2026-05-03-to-2026-05-05.md` 保存。
