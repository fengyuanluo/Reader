# Reader Implementation Task Plan

## Goal

严格按照 `docs/Requirement.md`、`docs/Design.md`、`docs/Tasks.md` 和根级 `AGENTS.md`，高质量完整实现 Go Web 服务，使用 `docs/Tasks.md` 作为主任务跟踪源，本文件作为阶段性执行跟踪补充。

## Global Rules

- 默认中文沟通和项目文档。
- 不修改 `legado/`，只将其作为源码事实来源。
- OpenAPI-first：先更新 `api/openapi.yaml`，再生成代码，再实现 handler。
- 每个任务开始先检查 git 状态并阅读任务列出的 Legado 原实现。
- 每个代码任务先新增或更新测试，再实现代码。
- 常规代码任务至少运行 `go generate ./...`、`go test ./...`、`go vet ./...`。
